# Yet Another Set of Lua Modules

Yalms is a collection of reusable Lua modules. It provides an out-of-the-box solution to common problems.

> [!NOTE]
> Yalms is not yet packaged for LuaRocks and is currently undocumented.
> At this stage, you may prefer to copy paste the modules until the project is released.
